# หารด้วย — ผู้ช่วยหารค่าเที่ยว

เว็บสำหรับหารค่าใช้จ่ายทริปกับเพื่อน: เพิ่มสมาชิก → บันทึกค่าใช้จ่าย → คำนวณว่าใครต้องโอนให้ใคร → ส่งลิงก์รายงานพร้อม QR พร้อมเพย์

เป็นเว็บแบบ static (HTML/CSS/JS ล้วน) ไม่ต้องมี server หรือ database

## หน้าในเว็บ

| ไฟล์ | หน้า |
|---|---|
| `index.html` | หน้าแรก: ภาพรวมทริป ขั้นตอน ข้อมูลตัวอย่าง ล้างข้อมูล |
| `members.html` | 1. เพิ่ม / แก้ไข / ลบสมาชิก พร้อมเบอร์พร้อมเพย์ |
| `expenses.html` | 2. เพิ่ม / แก้ไข / ลบค่าใช้จ่าย เลือกคนจ่ายและคนหาร |
| `summary.html` | 3. คำนวณยอดแต่ละคน ใครโอนให้ใคร QR พร้อมเพย์ และปุ่มติ๊กว่าโอนแล้ว |
| `report.html` | 4–5. Final report + คัดลอกลิงก์ / ส่ง LINE / พิมพ์ PDF |
| `view.html` | หน้าที่เพื่อนเห็นเมื่อเปิดลิงก์รายงาน (ดูอย่างเดียว) |

## เอาขึ้นออนไลน์ (ฟรี)

ลิงก์รายงานจะส่งให้เพื่อนเปิดได้ก็ต่อเมื่อเว็บอยู่บนอินเทอร์เน็ต เลือกวิธีใดวิธีหนึ่ง:

### วิธีที่ 1: Netlify Drop (ง่ายที่สุด ~1 นาที)
1. เข้า https://app.netlify.com/drop แล้วสมัคร/ล็อกอิน (ใช้บัญชี Google หรือ GitHub ได้)
2. ลากโฟลเดอร์ `Web` ทั้งโฟลเดอร์ไปวางในหน้าเว็บ
3. จะได้ URL แบบ `https://ชื่อสุ่ม.netlify.app` ใช้ได้ทันที
4. (ไม่บังคับ) เปลี่ยนชื่อได้ที่ Site configuration → Change site name
5. ครั้งต่อไปที่แก้ไฟล์: เข้าไซต์ → Deploys → ลากโฟลเดอร์วางใหม่

### วิธีที่ 2: GitHub Pages
1. สร้าง repository ใหม่ที่ https://github.com/new (ตั้งเป็น Public)
2. กด "uploading an existing file" แล้วลากไฟล์ทั้งหมดในโฟลเดอร์ `Web` (รวมโฟลเดอร์ `css`, `js`) ไปวาง → Commit changes
3. ไปที่ Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save
4. รอ 1–2 นาที จะได้ URL แบบ `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/`

## หมายเหตุ
- ข้อมูลทริปเก็บใน localStorage ของเบราว์เซอร์แต่ละเครื่อง
- ลิงก์รายงานเก็บข้อมูลทั้งหมดไว้ใน URL เอง (บีบอัดแล้ว) ถ้าแก้ข้อมูลภายหลังต้องส่งลิงก์ใหม่
- เพื่อนที่ได้ลิงก์กด "นำเข้าไปแก้ไขต่อ" เพื่อแก้ข้อมูลในเครื่องตัวเองได้
- QR พร้อมเพย์ใช้มาตรฐาน Thai QR Payment (EMVCo) ใส่ยอดเงินให้อัตโนมัติ รองรับเบอร์มือถือ 10 หลัก / เลขบัตรประชาชน 13 หลัก / e-Wallet 15 หลัก
